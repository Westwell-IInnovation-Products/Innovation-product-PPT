# Innovation-Products_ppt 主题参考材料

本目录随团队分享版提供三套主题参考材料。页数不要求一致：重点是让使用者看清各主题的版式能力和视觉特征，而不是把三套材料强行做成同一种结构。

| 主题 ID | PPT 文件 | 页数 | 材料来源 | 主要识别特征 |
|---|---|---:|---|---|
| `leander-base` | `01-leander-base-reference.pptx` | 27 | 用户提供的参考 PPT | 暖白底、红规线、藏蓝标题、线框与文字主导 |
| `base2` | `02-base2-reference.pptx` | 17 | 用户提供的参考 PPT | 白色圆角卡、柔和阴影、红与淡红状态语义 |
| `leander-global` | `03-leander-global-sample-13p.pptx` | 13 | Innovation-Products_ppt 工作流制作的分享样稿 | 英文优先、白底蓝色技术架构、流程与证据布局 |

每套 PPT 旁边都有一张 `contact-sheet` 总览图。先看总览图判断方向，再打开 PPT 查看单页细节和可编辑结构。

## 使用边界

- 两份 `reference.pptx` 是团队提供的原始参考材料，主要用于学习版式、信息密度、配色、图示和图片布局。
- `leander-global` 是本次重新制作的 13 页分享样稿，可用于展示该主题的当前实现效果。
- 参考材料不代表 Skill 会自动复刻其中的业务内容。正式出片仍需走大纲、布局蓝图、标杆样张和全量生产关卡。
- 两份参考 PPT 已按本次确认纳入当前分享版。后续替换、增补材料或改变分享范围时，仍应重新检查文字、图片、备注、链接和文档属性。

## 快速查看

1. 在 GitHub 页面直接点击总览图。
2. 需要看完整页面时，下载对应 PPT。
3. 需要选主题时，对照上表和 [`../../references/THEMES.md`](../../references/THEMES.md)。
