# Internal PPT Template

## Overview

Use this skill to turn raw content into a coherent internal presentation system: narrative structure, reusable page patterns, visual rules, and final review standards.

Prefer a calm, precise, business-facing style. Optimize for executive scanning, meeting discussion, and repeated internal reuse rather than marketing impact.

## Workflow

1. Identify the deck scenario: management update, strategy proposal, project review, data analysis, roadmap, training, or decision memo.
2. Define the audience and decision goal in one sentence.
3. Build the slide outline around one governing storyline: conclusion first, evidence second, action last.
4. Select page patterns from `references/template-paradigm.md`.
5. Apply visual and writing rules from `references/template-paradigm.md`.
6. Before delivery, run the review checklist in `references/review-checklist.md`.

## Output Standards

For a new deck, produce:

- A slide-by-slide outline with slide title, page type, key message, and suggested visual layout.
- A reusable template rule set: colors, typography, spacing, chart style, table style, and icon usage.
- Speaker-facing notes only when the user asks for a script or presentation notes.

For an existing deck review, produce:

- A diagnosis grouped by structure, message, visual hierarchy, data clarity, and template consistency.
- Concrete rewrite suggestions for weak slide titles and overloaded pages.
- A prioritized fix list that can be applied quickly.

For actual PPTX creation, use an appropriate presentation-generation skill or tool after applying this skill's paradigm.
